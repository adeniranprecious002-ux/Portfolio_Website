An autonomous QA pipeline that goes beyond UI regression testing into calculation validation — it independently recomputes expected values from raw input data, compares them against live API output, and when a mismatch is found, uses an LLM to explain the likely root cause and suggest a follow-up test instead of firing a generic threshold alert. Runs on a schedule with full observability into a live dashboard.

  • Independent recalculation — not a threshold ping, true calculation validation
  • AI-generated root-cause analysis on every anomaly (formula drift, rounding, stale cache)
  • Severity tiers (none / medium / high) with Slack alerting
  • Every check logged to Supabase with DB-level duplicate prevention
  • Live dashboard — pass rate, anomaly history, likely cause
  • Isolated error-handling workflow separate from anomaly detection
